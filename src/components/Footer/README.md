# Footer

The site footer (`.foot`) — brand block, the three link columns
(Treatments / Fuel Lab / Club), opening hours and the legal row.

**Used by:** App (src/App.jsx) — last top-level sibling in the outer
fragment, after `</main>`.

**Contains:** `footer.foot` > `.wrap` > `Brand` + `Columns` + `Hours` +
`Legal`.

## Modify
- Change the brand block → `Brand/`.
- Change the link columns → `Columns/`.
- Change the opening hours → `Hours/`.
- Change the legal row → `Legal/`.
