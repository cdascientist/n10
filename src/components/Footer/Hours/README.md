# FooterHours

The opening-hours row (`.hours`) — four `<b>day + span>` entries
(Mon–Thu / Fri / Sat–Sun / quiet hours).

**Used by:** Footer (src/components/Footer/index.jsx) — third child of
`.wrap`, after the link columns.

**Contains:** `div.hours` > 4 × `div` (`b` + text).

## Modify
- Change the hours / days → `index.jsx`.
