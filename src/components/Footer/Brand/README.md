# FooterBrand

The footer brand block (`.foot-brand`) — the `#mark` logo link, the
one-line tagline and the licensed-massage badge.

**Used by:** Footer (src/components/Footer/index.jsx) — first child of
`.wrap`, before the link columns.

**Contains:** `div.foot-brand` > `a.logo` (svg + `span.logo-type`) +
`p` + `span.badge` (svg `use#i-shield` + text).

## Modify
- Change the tagline, badge or logo → `index.jsx`.
