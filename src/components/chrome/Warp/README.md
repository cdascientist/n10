# Warp

The full-viewport warp/vignette overlay — five empty `<i>` tiles that
effects.js animates as the decorative grid-warp behind the scenes.

**Used by:** App (src/App.jsx) — fifth top-level sibling, after
PromoSticker.

**Contains:** `#warp` with five empty `<i>` elements.

## Modify
- Add/remove warp tiles → `index.jsx` (keep `id="warp"`).
- The warp motion lives in effects.js.
